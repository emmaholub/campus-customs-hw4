# Campus Customs usability improvements

## Front end

1. Instant catalogue search/filter: shoppers can narrow the collection by words such as “hoodie,” “Yale,” or “gift” without waiting for another page.
2. Structured chat product cards: recommendations show an image, name, price, and short description with a direct link to the product page, making the assistant useful for shopping rather than only conversational.

## Agent/backend

1. Mandatory database tools for price and stock: the assistant checks SQLite for commerce facts instead of guessing, reducing incorrect prices and availability claims.
2. Concise schema-constrained replies: the agent returns a predictable message plus typed product cards, which makes the experience easier to scan, safer to render, and cheaper than returning unnecessary prose.

Together these choices reduce search effort, improve trust in inventory answers, and create a direct path from a question to a product detail page.
